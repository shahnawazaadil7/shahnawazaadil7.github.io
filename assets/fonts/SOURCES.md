# Self-hosted fonts

Downloaded unchanged from official Google Fonts sources on 27 October 2026. Both fonts use the SIL Open Font License 1.1; the corresponding license files are included here.

| Local file | Style / requested weights | Official download | License |
| --- | --- | --- | --- |
| `manrope-latin-variable.woff2` | Manrope, normal, variable 400–800, Latin subset | [Google Fonts WOFF2](https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSvfedN4.woff2) | `Manrope-OFL.txt` ([source](https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt)) |
| `ibm-plex-mono-latin-regular.woff2` | IBM Plex Mono, normal, regular 400, Latin subset | [Google Fonts WOFF2](https://fonts.gstatic.com/s/ibmplexmono/v20/-F63fjptAgt5VM-kVkqdyU8n1i8q131nj-o.woff2) | `IBMPlexMono-OFL.txt` ([source](https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexmono/OFL.txt)) |

The WOFF2 URLs were selected from the `/* latin */` blocks in the official Google Fonts stylesheets for [Manrope 400–800](https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&display=swap) and [IBM Plex Mono 400](https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400&display=swap), requested with a current Chromium user agent. Local font files were checked for the WOFF2 signature, and both included licenses were checked for the SIL Open Font License text.
